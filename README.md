# İngilizce Öğretmen

Sesli İngilizce konuşma pratiği uygulaması (Android için PWA). Arkada OpenAI API çalışır.

- Canlı Sohbet (Realtime) ve Bas-Konuş modları
- Seviyeye göre (A1 → C2+) otomatik ayarlanan öğretmen
- 157 konuluk dilbilgisi ve konuşma durumu listesi
- Günün kelimeleri, hata bankası, ders sonu özetleri

API anahtarı sadece telefonda saklanır; bu depoda yoktur.

**Durum:** v1.0 – tüm aşamalar tamamlandı (Bas-Konuş, Canlı Sohbet, seviye sistemi, hata bankası, kelime tekrarı, ders özeti, İlerleme)

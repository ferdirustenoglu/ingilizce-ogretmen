# Cümle Atölyesi

Türkçe cümleleri İngilizceye yazarak İngilizce kalıpları öğreten kişisel uygulama (Android için PWA).

- 10 ünite, 70 kalıp; her kalıp için kural kartı ve örnekler
- Yapay zekâ doğal Türkçe cümle üretir, cevabı kontrol eder ve öğretir (varsayılan model: OpenAI GPT-5.6 Terra)
- Ustalık puanı, 1-3-7 gün tekrar, hata defteri, yerleştirme testi
- Veriler ve API anahtarı sadece telefonda saklanır

Yayın: https://ferdirustenoglu.github.io/ingilizce-ogretmen/
